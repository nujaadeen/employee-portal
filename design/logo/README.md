# Logo

The screens use a stand-in mark (baracel-logo-placeholder.svg), not the real Baracel logo.
Put the real files here, with exactly these names, before running the prompts:

- baracel-logo-transparent.png  (for dark backgrounds)
- baracel-logo-dark.png         (on its own navy background)

The real logo's white text will not show on the light theme. Add a dark-text version (baracel-logo-light.png) when you have one.
