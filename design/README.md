# Baracel design kit

Unzip this folder as `design/` at the root of the baracel-employee-portal repo.

- screens/  9 PNG screenshots of the approved sample screens (1440px wide)
- html/     the same screens as standalone HTML (open in a browser)
- tokens.css, BRAND.md  colours, fonts, spacing and layout rules
- logo/     put the real Baracel logo files here

Screens: 01-login, 02-dashboard, 03-leave (manager view), 04-employees (non-manager),
05-employees-manager (My team tab), 06-tasks-board, 07-task-detail, 08-ai-assistant, 09-roles-access.
Fonts: the PNGs were rendered without Space Grotesk, so headings show in Inter. The app should use Space Grotesk as set in tokens.css.
